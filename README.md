# Enhancing NOC sequencing capacity and advancing marine biodiversity monitoring technologies

This repository contains the bioinformatic analyses associated with the NOC ICP Oxford Nanopore metabarcoding project, using environmental DNA (eDNA) samples collected with the RoCSI autonomous sampling system.

The project applies a Tree of Life metabarcoding approach to characterise biodiversity across multiple taxonomic groups using Oxford Nanopore Technologies (ONT) sequencing. Multiple molecular markers are used to target different components of the marine community, providing a broad assessment of biodiversity from the same set of environmental samples.
